# Asset Heavy · 产业产能地图

同一个 GitHub Pages 入口按产业链切换。默认打开 PCB，`?chain=fab` 直达晶圆制造和封装测试。

- PCB 图谱使用原发布文件 `pcb.html`，个人输入仍按原图谱的方式保存在浏览器。
- Fab 与封测的数据和来源位于 `fab-data.js`。项目设计产能、披露产能、实际产量和投资额保留原统计口径。合并口径单列，参股线的产能按披露的产线口径标注。
- 更新数据时维护企业、城市、项目和来源。新增产业链时加入 `index.html` 内的 `chains` 列表，并添加对应页面。
- 中国底图沿用原 PCB 图谱的 DataV 省界，城市坐标为中心点，近邻点有引线。境外基地在地图下方单列。

本地预览时从仓库根目录启动静态 HTTP 服务。
